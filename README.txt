프랭클린 플래너 (오프라인 + 자동 동기화 버전)

이 폴더의 파일을 GitHub 저장소에 그대로 올리면 앱이 됩니다.
- index.html            앱 본체
- firebase-config.js    Firebase 설정값을 붙여넣는 파일 (꼭 수정)
- sw.js                 오프라인 실행용
- manifest.webmanifest  홈 화면 설치용
- icon-192.png, icon-512.png  앱 아이콘
- firestore.rules       Firebase 보안 규칙 (Firebase 콘솔에 복사해 붙여넣기)

자세한 순서는 함께 드린 설정 안내서를 보세요.
